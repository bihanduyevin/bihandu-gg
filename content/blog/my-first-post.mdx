## Why Bihandu.gg?

I wanted a space where technology, geography, urban exploration, photography, and writing could exist together instead of feeling like completely separate interests.

The website is designed around that idea.

## The technology

The project uses Next.js, TypeScript, Tailwind CSS, client-side animations, and static generation.

Because the site is designed for GitHub Pages, the application is built around static output rather than a runtime database.
